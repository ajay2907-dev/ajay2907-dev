## 🚀 Featured Projects

### 🎯 FocusFlow

**Academic Assignment Management & Study Planning**

FocusFlow is an intelligent academic productivity application designed to transform complex coursework into an adaptive and manageable daily study schedule.

The application focuses on helping students understand their workload, prioritize assignments, identify risks, and make better decisions about how to use their available study time.

**Key Features**

* 🧭 Best Next Action recommendations
* 🧪 What-If scenario simulation
* 🛟 Deadline Rescue planning
* 🧬 Assignment effort and complexity profiling
* 🧠 Schedule confidence and risk scoring
* 🛣️ Critical-path and dependency management
* 🎯 Focus Mode with study-session tracking
* 📱 Mobile-first responsive interface
* 🧪 Automated unit and integration testing

**Technology Stack**

`Python` `Streamlit` `SQLAlchemy` `SQLite` `PostgreSQL` `Pandas` `Plotly` `Pytest` `CSS`

🔗 **Repository:**
https://github.com/ajay2907-dev/FocusFlow

### 💰 Student Expense Tracker

**Personal Finance Management for Students**

A full-featured financial management application designed for university students to track expenses, manage budgets, monitor savings goals, analyze spending patterns, and generate financial reports.

The application combines authentication, database management, financial analytics, interactive visualizations, and report generation into a single platform.

**Key Features**

* 🔐 User registration and authentication
* 🔒 Password hashing with bcrypt
* 👥 Multi-user data isolation
* 💳 Expense tracking and management
* 📊 Budget monitoring and alerts
* 🎯 Savings goal tracking
* 📈 Interactive financial analytics
* 🔎 Expense search and filtering
* 📄 CSV and PDF report generation
* 🔔 Smart notifications
* 🌓 Light and dark themes
* 📱 Responsive user interface

**Technology Stack**

`Python` `Streamlit` `SQLite` `SQL` `Pandas` `Plotly` `ReportLab` `bcrypt`

🔗 **Repository:**
https://github.com/ajay2907-dev/Student-expense-tracker
